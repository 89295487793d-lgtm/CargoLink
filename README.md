# CargoLink — стартовый MVP Telegram Bot + Mini App

## Запуск
1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN` и публичный HTTPS `WEBAPP_URL`.
3. `python -m pip install -r requirements.txt`
4. Терминал 1: `uvicorn api:app --host 0.0.0.0 --port 8000`
5. Терминал 2: `python bot.py`
6. Проверьте `/health`, затем укажите реальный публичный HTTPS-адрес в `WEBAPP_URL`.

## Важно
Это очищенный стартовый MVP, а не готовая к публичному запуску production-система. Включены профиль, заявки, предложения ставок, свободные авто, помощь на дорогах и отправка сообщений о контрагентах на модерацию. Не реализованы полноценный внутренний чат, взаимный обмен контактами, уведомления о ставках, админ-панель модерации, карта/геокодирование, вложения, аудит действий и автоматические задачи очистки.

`auth.py` пока использует заголовок `X-Telegram-Id` для разработки — это НЕ безопасная аутентификация для публичного запуска. До запуска реальных пользователей обязательно внедрить проверку подписи Telegram WebApp initData. Нужны также тесты, миграции Alembic, резервные копии, мониторинг, ограничение частоты запросов и проверка соответствия законодательству о персональных данных.

Не добавляйте реальный токен бота в GitHub. Храните его в Codespaces Secrets/переменных окружения.
