# CargoLink — стартовый MVP

Стартовый комплект Telegram-бота, API и мобильной стартовой страницы Mini App. Это не завершённая production-платформа.

## Запуск через Docker
1. Скопируйте `.env.example` в `.env`.
2. В `.env` укажите `BOT_TOKEN` от BotFather. Не публикуйте `.env` и не отправляйте токен в чат.
3. Запустите `docker compose up --build -d`.
4. Проверьте API: `http://localhost:8000/health`.
5. Проверьте интерфейс в браузере: `http://localhost:8000/`.
6. Логи бота: `docker compose logs -f bot`.
7. Отправьте боту `/start` в Telegram.

Для кнопки Mini App в Telegram задайте `WEBAPP_URL` как публичный HTTPS URL, ведущий на размещённый интерфейс. Локальный `http://localhost:8000/` Telegram Mini App не примет.

## Сейчас реализовано
- Telegram `/start` и главное меню.
- Сохранение ФИО и собственного номера телефона в PostgreSQL.
- API health-check; корневой адрес отдаёт интерфейс.
- Мобильная стартовая страница CargoLink.
- Docker Compose с PostgreSQL и отдельной инициализацией таблиц.

## Пока не реализовано
Поиск/публикация грузов, ставки, свободные авто как записи в БД, внутренний чат, взаимное раскрытие контактов, модерация, миграции Alembic, автоматические тесты и production hardening.

Профиль API намеренно не открыт публичным маршрутом: для доступа к персональным данным сначала потребуется авторизация. Не размещайте сервис публично с реальными персональными данными до настройки авторизации, миграций, резервного копирования, мониторинга и проверки требований к персональным данным.
